# 0x03. Unittests and Integration Tests

This project focuses on learning how to write **unit tests** and **integration tests** in Python using the `unittest` framework.  
You will practice parameterization, mocking, fixtures, and testing code behavior cleanly and effectively.

---

## Learning Objectives

By the end of this project, you should be able to:

- Explain the difference between **unit tests** and **integration tests**
- Use mocking with `unittest.mock`
- Use parameterized tests with `parameterized`
- Create fixtures for reusable test data
- Test edge cases and expected failures
- Run tests using:
  ```bash
  python3 -m unittest path/to/test_file.py
